# 🚗 Car Rental Management System

## 📌 Project Overview

The Car Rental Management System is a web-based application developed using
HTML, CSS, JavaScript, Python Django, and SQLite3.

The main purpose of this project is to allow users to view available cars,
register an account, log in, book cars, manage their bookings, and contact
the rental service.

The application provides a simple, user-friendly interface with colorful
designs, CSS animations, and car images.

## 🛠️ Technologies Used

- HTML5 – Web page structure
- CSS3 – Styling, colors, animations, and responsive design
- JavaScript – Interactive website features
- Python – Backend programming
- Django – Web framework
- SQLite3 – Database management

## ✨ Features

- 🏠 Home Page – Introduction to the car rental service.
- 👤 User Registration – Create a new account.
- 🔐 User Login – Authenticate registered users.
- 🚘 Available Cars – View available cars and their details.
- 📅 Car Booking – Book a car by selecting pickup and return dates.
- 📋 My Bookings – View personal booking details.
- 📩 Contact Page – Send messages to the rental service.
- 🗄️ Database Integration – Store user, car, booking, and contact information.
- 🎨 Attractive UI – Colorful backgrounds, CSS animations, and car images.
- 🔒 Authentication – Protect booking pages using Django login authentication.

## 🗄️ Database

The project uses SQLite3, Django's default database.

The main database models are:

- **Car** – Stores car information, prices, and availability.
- **Booking** – Stores customer bookings, dates, and total amounts.
- **Contact** – Stores customer contact messages.
- **User** – Stores user account information using Django's authentication system.
